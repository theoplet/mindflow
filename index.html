Google Drive Integration

📁
Not connected to Google Drive
Configure Client ID or Access Token
📖 Hướng dẫn lấy Client ID hoặc Access Token (Bấm để xem)
Cách 1: Lấy OAuth Client ID (Khuyên dùng - Đăng nhập 1-click):
  1. Truy cập Google Cloud Console.
  2. Tạo một Project mới $\rightarrow$ Vào APIs & Services $\rightarrow$ Library $\rightarrow$ Bật Google Drive API.
  3. Vào Credentials $\rightarrow$ Bấm Create Credentials $\rightarrow$ Chọn OAuth client ID.
  4. Chọn Application type: Web application.
  5. Tại Authorized JavaScript origins, thêm: http://localhost:3000.
  6. Sao chép mã Client ID thu được dán vào ô "OAuth Client ID" bên dưới và bấm Save.
Cách 2: Lấy Access Token Nhanh (Dùng ngay trong 1 phút):
  1. Truy cập Google OAuth 2.0 Playground.
  2. Ở danh sách bên trái, chọn Drive API v3 $\rightarrow$ Đánh dấu chọn https://www.googleapis.com/auth/drive.file.
  3. Bấm Authorize APIs và đăng nhập tài khoản Google.
  4. Bấm Exchange authorization code for tokens.
  5. Sao chép mã Access Token dán vào ô "Access Token (Direct)" bên dưới và bấm Use.
